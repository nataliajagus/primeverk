Cennik i kalkulator

Wszystkie ceny są bez VAT. To ceny bazowe, a każda realizacja jest dopasowywana do potrzeb klienta.

Wszystkie ceny bez VAT

Cennik

Malowanie

  • Malowanie – sama robocizna (ściany zagruntowane, odświeżenie)3.000 kr / m²

Szpachlowanie i naprawy

  • Szpachlowanie3.500–5.000 kr / m²
  • Szpachlowanie samych łączeń G-K (włóknina + dwie warstwy masy)4.000 kr / mb
  • Renowacja starych ścian (skrobanie, pęknięcia, prostowanie)od 5.000 kr / m²

Płytki i łazienki

  • Płytki podłogowe – standardowy rozmiar7.500 kr / m²
  • Płytki ścienne – standardowy rozmiar9.500 kr / m²
  • Wielki format (np. 60×120 cm) lub mozaiki14.000 kr / m²
  • Skuwanie starych płytek6.000 kr / m²
  • Płynna folia z taśmami uszczelniającymi w strefie mokrej2.800–4.000 kr / m²

Podłogi

  • Układanie paneli w systemie „klik”1.800–2.300 kr / m²
  • Układanie paneli winylowych na klej4.000 kr / m²
  • Masa samopoziomująca (wylewka, z materiałem)4.000 kr / m²
  • Zrywanie starej podłogi i przygotowanie podłoża2.000 kr / m²

Pomieszczenia o nieregularnych kształtach (wąskie korytarze, dużo filarów, obróbka wokół rur od grzejników) podnoszą koszt robocizny ze względu na czas potrzebny na precyzyjne docinanie materiału.
