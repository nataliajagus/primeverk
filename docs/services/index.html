Þjónusta

Fimm sérsvið í frágangi. Veldu eitt eða sameinaðu nokkur í eitt verk.

Málun

Málun veggja og lofta með vandaðri vörn á yfirborðum og hreinum línum.

  • Vörn á gólfum, gluggum og innréttingum
  • Smávægilegur undirbúningur yfirborðs
  • Málun veggja og lofta
  • Hreinar línur og skil milli lita
  • Málun – eingöngu vinna (grunnaðir veggir, upplyfting)3.000 kr / m²

Spartl og lagfæringar

Sléttir fletir fyrir málun – allt frá spartli á samskeyti til fullrar endurnýjunar á gömlum veggjum.

  • Spartl á heila veggi og loft
  • Samskeyti gipsplatna: glertrefjanet og tvær umferðir af massa
  • Viðgerðir á sprungum og skemmdum
  • Rétting á ójöfnum veggjum
  • Spartl3.500–5.000 kr / m²
  • Spartl á samskeyti gipsplatna eingöngu (glertrefjanet og tvær umferðir af massa)4.000 kr / m
  • Endurbætur á gömlum veggjum (skafið, sprungur, rétt af)frá 5.000 kr / m²

Flísalögn

Gólfflísar, veggflísar og stór flísasnið lögð jafnt og með beinni fúgu.

  • Lagning gólfflísa og veggflísa
  • Stór flísasnið og mósaík
  • Nákvæm sögun og jöfnun
  • Fúgun
  • Gólfflísar – staðalstærð7.500 kr / m²
  • Veggflísar – staðalstærð9.500 kr / m²
  • Stór flísasnið (t.d. 60×120 cm) eða mósaík14.000 kr / m²

Baðherbergi

Baðherbergi frá grunni: brot, vatnsvörn votrýmis og nýjar flísar.

  • Brot á gömlum flísum
  • Vatnsvarnarefni með þéttiböndum
  • Gólfflísar og veggflísar
  • Stór flísasnið og mósaík
  • Gólfflísar – staðalstærð7.500 kr / m²
  • Veggflísar – staðalstærð9.500 kr / m²
  • Stór flísasnið (t.d. 60×120 cm) eða mósaík14.000 kr / m²
Skoða þjónustu

Gólfefni

Plastparket með smellukerfi og vínylgólf, jöfnunarmassi og fjarlæging gamalla gólfefna.

  • Plastparket með smellukerfi
  • Vínylgólf með límingu
  • Jöfnunarmassi
  • Fjarlæging gamals parkets, flísa eða teppis
  • Lagning plastparkets með smellukerfi1.800–2.300 kr / m²
  • Lagning vínylgólfs með límingu4.000 kr / m²
  • Jöfnunarmassi (gólfjöfnun, með efni)4.000 kr / m²
